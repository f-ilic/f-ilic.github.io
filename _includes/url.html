{%- comment -%} Outputs a link target from front matter: external URLs are kept as-is, site paths such as "papers/x.pdf" are made root-relative so they resolve from any page (not only from the homepage). Usage: include url.html with url=page.paper {%- endcomment -%} {%- if include.url contains "://" -%} {{- include.url -}} {%- else -%} {{- include.url | prepend: "/" | replace: "//", "/" | relative_url -}} {%- endif -%}
