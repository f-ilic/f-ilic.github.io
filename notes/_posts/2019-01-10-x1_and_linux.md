After some initial hiccups I'm really liking Lenovos X1 Carbon Gen6 in combination with Linux.
Before being content though there are some fixes that you need to perform.
The following issues and fixes were tested in **Linux Mint 19.1**, but are probably the same for **Ubuntu 18.04, 18.10,** and **19.04**.

## Trackpad and Trackpoint not working
---

If your Laptop has an NFC chip you'll crap your pants after your first boot. Neither the trackpad nor the trackpoint work out of the box.
The fix for this is to adjust some boot parameters:
1. In the file```/etc/modprobe.d/blacklist.conf``` delete the line with ```i2c_i801```.
2. In the file ```/etc/default/grub```, add ```psmouse.synaptics_intertouch=1``` to the line ```GRUB_CMDLINE_LINUX_DEFAULT= <HERE>```.
3. Then run ```sudo update-grub```.
Note: This needs to be done after every kernel update.


_(There are already patches out there that fix this, so it's likely it will get merged upstream at some point.)_

## Mousebuttons occasionally stop working
---
This is a seperate issue from the previous one. It mostly happens after resuming from suspend.
The fix is quite easy:
```
#!/bin/bash 
#fix non-responsive trackpad and trackpoint
echo -n "none" | tee /sys/bus/serio/devices/serio1/drvctl
echo -n "reconnect" | tee /sys/bus/serio/devices/serio1/drvctl
```

## Headphone crackle
---

```
#!/bin/bash 
#https://askubuntu.com/questions/910221
#fix crackling sound from headphones
#downside: small crackling when moving mouse
hda-verb /dev/snd/hwC0D0 0x20 SET_COEF_INDEX 0x67
hda-verb /dev/snd/hwC0D0 0x20 SET_PROC_COEF 0x3000
```

You additionally might also need to disable one of the PINs if you are experiencing heaphone crackles while charging with:

```hda-verb /dev/snd/hwC0D0 0x1d SET_PIN_WIDGET_CONTROL 0x0```

Note: ```hda-verb``` needs sudo privileges.
